# AI Usage Log

This log records how ChatGPT was used as a learning assistant while preparing this project. 

| AI Tool | Prompt / Question Asked | How I Used / Verified the Response |
| ChatGPT | "Explain how to make a simple student record management project in C using structures, arrays and functions." | I used the explanation to plan the structure of the program. I checked that the student details were stored in a structure and that an array could hold multiple records. |
| ChatGPT | "Suggest a simple way to calculate CGPA from the SGPA values that are available." | I used the idea of adding completed semester SGPA values and dividing by their count. I checked the calculation with sample values manually. |
| ChatGPT | "Suggest simple CGPA-based academic advice categories that can be written using if-else statements in C." | I used four categories: Excellent Performance, Good Performance, Needs Improvement and Requires Immediate Attention. I reviewed the ranges and implemented the final messages using if-else statements. |
| ChatGPT | "Give sample test cases for adding, searching, sorting and deleting student records." | I used sample student records to check the program flow. I also checked the CGPA and advisor examples against the values entered. |
| ChatGPT | "Help me prepare a simple README and explain the GitHub files required for this assignment." | I used the outline to prepare the README and repository checklist, then checked the sections against the assignment instructions. |
